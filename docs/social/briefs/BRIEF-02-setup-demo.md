# Brief 02 — Actual product setup demonstration

Draft: 2026-09-21 · L09 · Parent: `docs/social/CONTENT_EXPERIMENT.md`.

Status: **NOT CAPTURED.** Blocked on: L04 camera/media sign-off (the count may
not be shown before it) and one consenting adult with a signed release.
Reusable for Days 3, 5, 8, 10, 12 and 1.

Runtime 17–22 s · 1080×1920 · 30 fps · burned-in captions · real app UI only.

Hypothesis: an honest "set your phone up like this" demo converts viewers who
own a phone but have never filmed themselves exercising.

## 1. Cast, footage and permissions

| Need | Detail |
| --- | --- |
| People | one consenting adult + operator; signed release as in Brief 01 |
| Permissions | same release terms (recording + publication on the named project accounts); owner-held |
| Build | camera-enabled build after L04 sign-off; app version + artifact hash on the shoot sheet |
| Props | tripod or stable surface, normal room lighting, full-body space |
| Music | platform library or original; one music ledger row (`ASSET-02`) |

## 2. Shoot script

| Time | Visual | Audio / caption | Notes |
| --- | --- | --- | --- |
| 0–3 s | Phone propped up; person walks into frame, stops too close; the app's own framing guide shows the problem | Caption: "Your phone needs to see your whole body." | Problem hook, no claim yet |
| 3–10 s | Real device placement and framing: distance, height, light; follow the app's own setup guidance on screen | Caption: "Stand back. Whole body in frame. Steady light." | Show only what the app actually instructs |
| 10–17 s | Unscored practice explicitly labeled as practice, then a real count from the real camera UI | Caption: "Practice first. Then the real count." | Do not show a count if the captured build has counting off; do not fake one |
| 17–22 s | Real verified behavior on screen (e.g. the on-device processing statement from the app or the platform materials) + end card | Caption: "Counting runs on your phone." CTA per gate | Only verified wording; see red lines |

## 3. Edit, disclosure, CTA

- Real UI only; no mockups or motion-graphic substitutes for the camera view.
- If footage comes from a camera-off build (possible today), the asset cannot
  show a count — limit it to framing/onboarding and label the caption
  "camera counting not enabled in this build", or hold the asset until L04
  signs.
- No AI elements expected; if any are added, Brief 03 labeling applies.
- CTA gate: same as Brief 01 (follow-only today).

## 4. Red lines

No accuracy percentage, no "works on every phone/lighting", no medical or
calorie claims, no fake frames or mocked UI, no framing advice that contradicts
the app's own guidance, no claim about counting on a build where counting is
off.
