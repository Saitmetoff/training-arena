# Brief 04 — Curiosity-hook cuts (same real footage, new openings)

Draft: 2026-09-22 · research (parent: `docs/research/COMPETITIVE_ANALYSIS.md` §3)
· Companion: `docs/social/briefs/BRIEF-01-real-battle.md`,
`docs/social/CONTENT_EXPERIMENT.md` (this formalizes the Day 14 row and can be
used on any day whose real footage supports the hook).

Status: **NOT CAPTURED.** Blocked on the same gates as Brief 01: L04
camera/media sign-off, hosted stack + signed build (L05/R9), two consenting
adult testers with signed releases.

Runtime 8–15 s per cut · 1080×1920 · 30 fps · burned-in captions · **real
footage only, re-cut from Brief 01/02 masters**. One master, several openings;
no new shoot required.

Hypothesis: an opening that reads as a question the viewer would ask
themselves holds attention longer than a product premise, and one master
supports several honest openings. Success is still a first confirmed battle
(activation) per `CONTENT_EXPERIMENT.md` §1 — never a view.

## 1. What may and may not be re-cut

| Allowed | Not allowed |
| --- | --- |
| New opening caption over the existing real footage | New footage, re-enactments or generated UI |
| Reordering existing real scenes | Re-timing or speeding up a round to look live |
| Different end-card CTA per the gate table below | Any result, score, count or reaction the server did not confirm |
| New music row in the music ledger | Unlicensed music or third-party logos |

## 2. Hook candidates

Hooks are **captions or spoken lines by the consenting participants**, never
presented as quotes from an organic user or a testimonial. Each cut must pass
its truth check at publish time.

| # | Opening (first 2 s) | Source footage | Truth check |
| --- | --- | --- | --- |
| H1 | "What is this?" (viewer question over the raw round) | Brief 01 round scene | No claim made; caption is a question, not a quote |
| H2 | "Two phones. One live round." | Brief 01 split screens | Both devices in frame, real round |
| H3 | "The last five seconds changed it." | Brief 01 close match | Only when the real outcome was close; never manufactured |
| H4 | "The challenger lost." | Brief 01 result scene | Only with the real losing outcome and participant release |
| H5 | "Same clock. Same exercise." | Brief 01 round scene | True; no accuracy percentage, no "cheat-proof" |
| H6 | "We tied." | Brief 01 draw scene | Only with a real draw (calendar Day 7) |

## 3. Edit, disclosure, CTA

- Edit: no UI compositing, no invented overlays, no accuracy callouts. Real
  captured frames of the real build only. If a clip is compressed, label it
  "sped up" — never present it as real time.
- Disclosure: fully real assets carry no AI label. If any element is generated
  (voice, caption art), apply the Brief 03 labeling rules instead.
- CTA gate: today "Follow for beta updates" only. The invite CTA
  ("Get the beta and challenge a friend" + link) appears only when a working
  destination exists (`ACCOUNTS.md` §5) and the specific asset is approved.

## 4. Red lines

No fabricated score, receipt, rating or reaction; no edited or re-timed count;
no outcome the server did not confirm; no accuracy percentage; no
"cheat-proof"; no fitness transformation; no caption implying an organic user
said it; no third-party music or logos without a ledger row.

## 5. Publish checklist

- [ ] Cut is from an approved Brief 01/02 master; build hash on the shoot sheet.
- [ ] Consent and music ledger rows cover the new cut (new music row if changed).
- [ ] Hook's truth check in §2 passes at publish time.
- [ ] Caption and CTA true at publish time; owner approved this asset id.
- [ ] Post URL and hook id (H1–H6) recorded in the per-post ledger so the
      experiment can compare activation-per-qualified-visit across openings.
