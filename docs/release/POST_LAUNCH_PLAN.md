# Post-launch plan — conditional on functional owner acceptance

Do not implement this roadmap before the camera/friend-battle acceptance build
works and the owner has tested it. The active release plan is
[OWNER_ACCEPTANCE_2026-10-22.md](OWNER_ACCEPTANCE_2026-10-22.md).

1. **Observed usability first.** Review first-session attempts, failed sign-ins,
   invitation loss, preparation abandonment, count complaints and completed
   rounds. Fix the largest demonstrated friction; retain honest recovery copy.
2. **Design consistency.** Consolidate spacing/type/action hierarchy only where
   actual screens conflict or hinder use. Preserve readable live counts and
   opponent/status information at small screens and large text sizes.
3. **Accessible motion.** Review countdown, state transitions, result feedback
   and reconnect indicators. Motion must clarify state, honor reduced motion,
   avoid distracting from exercise and stay responsive on target hardware.
4. **Events and competitions.** Consider scheduled friend windows and small
   consensual challenges only after real battle reliability and voluntary
   return are measured. Define timezone, cancellation, fair scoring, support,
   reporting/moderation and capacity before any event promise or automation.
5. **Community/product expansion.** Choose additions from retained usage and
   user feedback. Ranked, push, additional game systems, billing and major
   progression remain separate decisions with their own evidence and operating
   requirements. No new dependency, purchase or feature is implied here.

Measure supported activation, completed full rounds, source-tagged confirmed
interest and voluntary return after a full seven-day observation window.
Report counts/denominators and unresolved defects; do not equate test totals,
event totals or waitlist size with retained players or proven growth.

Existing marketing constraints remain: repeated continuous 60-second silent
actor-only source, owner editing/adding app and meme audio, no owner-self-filming
assumption, and no claimed zero-cost generator solution. Video generation,
campaign sending and public posts are outside this execution.
