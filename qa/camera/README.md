# Camera QA evidence (task 03)

This folder holds the reproducible host evidence for the camera/counter layer
and the physical-device checklist that gates a camera-counted release.

| File | Generated by | Meaning |
| --- | --- | --- |
| `evidence/flutter_analyze_camera.txt` | `flutter analyze lib/camera test/camera` | analyzer is clean for the owned paths |
| `evidence/flutter_test_camera.txt` | `flutter test test/camera` | 54 counter/session/bridge/preview tests |
| `evidence/apk_build.txt` | `flutter build apk --debug` | Android build with the native bridge |
| `evidence/apk_manifest_evidence.txt` | `aapt dump badging` + APK inspection | package, min/target SDK, camera permission and optional features, bundled ML Kit pose model |
| `device_validation_checklist.md` | task `10` on physical devices | release gate; currently empty |

Interpreting the evidence: host checks prove the state machines, protocol and
build. They are not accuracy evidence. The uncertain claims and the
release-blocking threshold are in `docs/camera/CAMERA_QA.md`.

Evidence was last regenerated on 2026-09-22 at the L02 toolchain (Flutter
3.47.5 / Dart 3.13.4, targetSdk 36), after the camera paused-state hardening
(5 new session tests).

Regenerate the host evidence (from `app/`):

```powershell
flutter analyze lib/camera test/camera | Out-File -Encoding utf8 ..\qa\camera\evidence\flutter_analyze_camera.txt
flutter test test/camera | Out-File -Encoding utf8 ..\qa\camera\evidence\flutter_test_camera.txt
flutter build apk --debug | Out-File -Encoding utf8 ..\qa\camera\evidence\apk_build.txt
```

The APK path referenced by the manifest evidence is
`app/build/app/outputs/flutter-apk/app-debug.apk`; rebuild it before rerunning
`aapt` if it is missing.
