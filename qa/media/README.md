# Athlete media QA evidence

Owned by task `02`. Everything here is generated by `qa/media/tools/` and is
safe to delete and regenerate. All shipped media is currently
`pending_human_review`, so this evidence is review input, not release approval.

| Artifact | What it proves | Generated by |
| --- | --- | --- |
| `identity_strip.png` | Same athlete (kit, visor, proportions) in all four key poses | `qa_report.py` |
| `contact_sheet_athlete.png` | Start / mid / end for both exercises at one camera and scale | `qa_report.py` |
| `contact_sheet_posters.png` | The four annotated fallback posters | `qa_report.py` |
| `loop_keyframes_pushup.png`, `loop_keyframes_squat.png` | What the loop videos actually contain, six samples each | `qa_report.py` |
| `legibility_360dp.png` | Poster at 512 px and scaled to 360 dp; smallest cue ≥ 14 dp at 360 dp and 328 dp | `qa_report.py` |
| `glb_roundtrip_check.png` | Rendering the GLB back through its own skinning matches the build pipeline | `qa_report.py` |
| `qa_report.json` | Machine-readable copy of the above (including GLB vertex error) | `qa_report.py` |
| `validation_report.json` | Manifest integrity, hashes, budgets, fallback resolution (prototype gate) | `validate_media_package.py` |
| `validation_report_release.json` | Release-gate result; currently fails by design until human review | `validate_media_package.py --gate release` |
| `tools/` | Generator, QA and validation scripts; `tools/build.py` rebuilds the package | — |

Review procedure and per-exercise criteria: `docs/media/FORM_REVIEW.md`.
Provenance and hashes: `docs/media/PROVENANCE.md`.

Regenerate from the repository root:

```powershell
python qa/media/tools/build.py
python qa/media/tools/qa_report.py
python qa/media/tools/validate_media_package.py
python qa/media/tools/validate_media_package.py --gate release
```
